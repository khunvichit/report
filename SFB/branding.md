# SFB — Branding / CHAW CI (reference for the daily report)

CHAW Corporate Identity values used by this report. The locked `sfb-template.html` is the
source of truth for layout; this file documents the CI it encodes so the routine can verify
on-brand output. Do not restyle the template from here — only keep these values in sync.

## Typeface
- **Poppins** for all text (headings, body, labels). Email falls back to
  `-apple-system, sans-serif` where Poppins is unavailable.
